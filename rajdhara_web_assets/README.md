## Recommended light theme
Use a premium real-estate light look:
- Off-white page background: `#F8FAFC`
- White cards: `#FFFFFF`
- Deep navy headings: `#0F2747`
- Rajdhara blue: `#0B8FE8`
- Deep blue CTA/nav: `#0B3D91`
- Orange accent: `#FF6A00`
- Soft borders: `#E2E8F0`

The orange should be used sparingly for arrows, small labels, CTA highlights, and active states.
